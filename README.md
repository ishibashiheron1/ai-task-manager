# AI Task Manager

## Project Description

AI Task Manager is a simple web application that allows users to create and manage their personal tasks. Users will be able to create an account, log in, add tasks, edit tasks, mark tasks as completed, and delete tasks. Task information will be stored in a database so users can access their tasks after logging back in.

## Main Features

- User registration
- User login and logout
- Add new tasks
- View existing tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks

## Data

Each task will contain:

- Task title
- Completion status
- User associated with the task
